No accounts, keys, paid APIs, subscriptions, remote assets, paid fonts, templates, analytics or cloud providers are configured. React, Electron, Radix, Tailwind, Lucide and Motion can be used without a subscription. The shadcn-style local component source uses MIT-licensed Radix/cva/clsx conventions. The original icon is generated by scripts/generate-icon.py. System fonts require no separately purchased font.

Electron and its bundled Chromium/Node components carry additional third-party notices inside the packaged app (LICENSE and LICENSES.chromium.html). Preserve those notices when redistributing. Development tools include transitive dependencies with their own permissive or dual licenses; source package notices remain in node_modules and the lockfile records identities. Npm funding metadata is optional donation information.

Local ad-hoc macOS signing uses codesign without an Apple certificate or Developer Program membership. Distribution is not notarized. Context7 documentation lookup used free keyless access; Playwright MCP ran locally. Neither MCP is needed at runtime. No OpenAI API or paid model call was made by application code.
